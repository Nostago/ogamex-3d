# OGameX-3D als lokale Demo

## Aktuelle Version 0.2

[OGameX-3D-0.2.zip herunterladen](OGameX-3D-0.2.zip): Auf der GitHub-Dateiseite
**Download raw file** (Download-Symbol) wählen. Die ZIP-Datei entpacken und
`OGameX-3D-0.2.html` mit Safari, Chrome, Firefox oder Edge öffnen.

Neu: detailliertere Gebäudemodelle mit Betriebsanimationen, sanfter Kamerafokus,
Übersichtstaste sowie Baugerüst, Scanring und Fortschrittsanzeige beim Ausbau.
Während eines Baus kann mit Reset oder Orbitwechsel abgebrochen werden.
Die Einstellung „Bewegung reduzieren“ wird berücksichtigt.

Es sind keine Installation und kein Server nötig. Die HTML-Datei enthält alle
benötigten Assets und funktioniert ohne Internet. JavaScript und WebGL müssen
aktiviert sein. Alle Werte sind Beispieldaten; Ausbauten verändern keinen echten
Spielstand und werden beim Neuladen zurückgesetzt. Das vollständige Laravel-Spiel
ist nicht Teil des Downloads. Die Three.js-MIT-Lizenz ist in der HTML-Datei enthalten.

Das Paket wurde offline in Chromium geprüft: Rendering, direkter 3D-Klick,
Kamerafokus und Übersicht, Bauanimation und verzögerte Stufenänderung,
Bauabbruch durch Reset/Orbit, Stufenlimit, Drehung, Zoom, Mobilansicht,
reduzierte Bewegung und erneutes Laden. Keine HTTP-Anfragen oder Seitenfehler.
