# OGameX-3D 0.1 als lokale Demo

Die ZIP-Datei enthält den eigenständigen 3D-Prototyp mit Beispieldaten sowie eine
kurze Anleitung. Ein Webserver oder eine Installation sind nicht erforderlich.

## Herunterladen und öffnen

1. [ZIP-Datei öffnen](OGameX-3D-0.1.zip) und auf GitHub **Download raw file**
   (Download-Symbol) wählen.
2. Die heruntergeladene ZIP-Datei entpacken.
3. `OGameX-3D-0.1.html` in einem aktuellen Safari, Chrome, Firefox oder Edge öffnen.

JavaScript und WebGL müssen aktiviert sein. Die Demo funktioniert nach dem
Herunterladen ohne Internet. Ausbauten verändern nur die Beispieldaten und werden
beim Neuladen zurückgesetzt. Das vollständige Laravel-Spiel ist nicht enthalten.

Dieses Paket wurde aus dem Prototyp-Stand `e43c051b` erzeugt. Die eingebettete
Demo wurde in Chromium mit deaktiviertem Netzwerk auf Rendering, direkte
Gebäudeauswahl, Ausbau, Stufenlimit, Reset, Orbit, Rotation, Zoom und Mobilansicht
geprüft. Dabei entstanden keine HTTP-Anfragen oder JavaScript-Seitenfehler.
Die Three.js-MIT-Lizenz ist in der HTML-Datei enthalten.
