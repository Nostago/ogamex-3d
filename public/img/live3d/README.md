# Live 3D appearance assets

`planet-atlas.png` is an AI-generated fictional equirectangular diffuse planet
texture created for this project on 2026-11-13. It is used on the interactive
Three.js sphere, alongside procedural clouds and lighting. It is not a screenshot
or a replacement for game UI or live data. No remote image service is used at runtime.
The original procedural texture remains available if this optional image fails.
